### [Formula Student Driver Display](University_Projects/University_Glasgow_Racing/Dashboard_Screen_2026)

- Developed low-level STM32 firmware and a custom graphics/UI layer.

Autonomous embedded rover developed as a third-year engineering team project, combining embedded C++, sensing, motor control, and system integration.

**C++ · Mbed OS · KL25Z · State-Based Control · Ultrasonic Sensing · Colour Sensing · Bluetooth**

- Led the design, implementation, and integration of the rover system.
- Developed the core embedded control software for line following, obstacle avoidance, colour sensing, and manual control.
